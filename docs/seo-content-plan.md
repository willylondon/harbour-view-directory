# Harbour View Directory SEO + Content Plan

Grow Harbour View Directory traffic with pages that match real local-intent searches in Harbour View, Kingston 17, and the CMU area.

3. **Rental + student housing intent**

## Content publishing cadence
- Publish **3 local-intent posts per week**
- Focus on evergreen traffic first, news second
- Every post should internally link to:
  - `/directory`
  - `/rent-near-cmu` when relevant
  - `/post-ad` for business-owner-facing topics
  - `/contact` or `/report` when trust/corrections are discussed

## Rules for blog content
- Do **not** invent business-specific claims, prices, or opening hours
- Prefer practical search-intent language over generic brand copy
- Use Harbour View, Kingston 17, and CMU naturally in titles and headings
- Keep articles useful even when they are not naming specific businesses
- End each post with a CTA back into the directory or rentals page
